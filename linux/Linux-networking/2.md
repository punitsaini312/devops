Excellent question 👌 this is the moment subnetting really “clicks”.

You’re asking:

> Why does 192.168.4.0/22 go up to 192.168.7.255?
Why 4 to 7?
> 

Let’s make it crystal clear.

---

🔹 Step 1: Remember the Block Size

For /22

Subnet mask:

255.255.252.0

Third octet = 252 (2^7+2^6+2^5+2^4+2^3+2^2+0+0)

Block size formula:

256 − 252 = 4

So networks jump by 4 in the 3rd octet.

Possible networks:

192.168.0.0
192.168.4.0
192.168.8.0
192.168.12.0
...

---

🔹 Step 2: What Does “Block Size = 4” Actually Mean?

It means:

Each network covers 4 full values in the third octet.

If network starts at 4:

4, 5, 6, 7

That’s 4 numbers.

Then next network starts at 8.

So:

Start = 4
End = (4 + 4 − 1) = 7

That’s the key formula:

Last octet in block = start + block size − 1

---

🔹 Step 3: Visual Way to See It

/22 means:

11111111.11111111.11111100.00000000

Look at third octet:

11111100

Last 2 bits are host bits:

xxxxxx00

2 host bits in third octet means:

2^2 = 4 possible values

Those 4 values are:

00 → 4
01 → 5
10 → 6
11 → 7

So third octet ranges from:

4 to 7

---

🔥 Why Broadcast Is 192.168.7.255

Because:

Third octet goes from 4 → 7

Fourth octet goes from 0 → 255

So the very last IP in this block is:

192.168.7.255

That’s broadcast.

---

🎯 Super Simple Rule

If block size is 4:

Start = 4
Next network = 8
So end = 7

Always:

End = next network − 1
